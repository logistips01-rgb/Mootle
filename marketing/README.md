# Material de marketing de Mootle

Recursos de marca y contenido para redes. **No forma parte de la web** (no se
enlaza desde el sitio ni va en el sitemap); vive aquí para tenerlo guardado.

## logos/
- `mootle-redes-ancho.png` (1600×900) — icono + logotipo + claim, fondo claro.
- `mootle-redes-cuadrado.png` (1080×1080) — fondo naranja, para post cuadrado.
- `mootle-perfil.png` (1000×1000) — solo el icono, para foto de perfil / avatar.
- `mootle-wordmark.png` (1600×520) — solo el logotipo "mootle".

## instagram/
- `mootle-ig-01..08.png` (1080×1080) — carrusel "cómo funciona Mootle", en orden.

## reels/
- `mootle-reel.mp4` (1080×1920, ~13 s, H.264) — reel animado. Sin música
  (añádela en Instagram/CapCut al subirlo).

## _fuentes/
Plantillas HTML con las que se generan los assets (se renderizan con Chromium/
Playwright y, el reel, se monta con ffmpeg). Editar aquí y volver a renderizar
para rehacer cualquier pieza manteniendo la marca (Inter Tight, naranja #e8590c,
las "oo" como ruedas).
